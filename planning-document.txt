2. DATA FLOW

Top-level state lives in App.jsx:
  - recipes        (array, loaded from data/recipesData.js on mount)
  - favorites       (array of recipe ids, persisted to localStorage)
  - mealPlan        (object keyed by day -> {breakfast, lunch, dinner})
  - isLoading        (boolean, set during initial data load)

Downward (parent -> child):
  - App passes `recipes`, `favorites`, `onToggleFavorite` to
    RecipesPage and FavoritesPage
  - RecipesPage passes filtered recipes to RecipeList
  - RecipeList passes one `recipe` object + `isFavorite` +
    `onToggleFavorite` to each RecipeCard
  - App passes `mealPlan`, `onAddMeal`, `onRemoveMeal` to
    MealPlannerPage -> MealPlanner -> each DayCard (with that
    day's slice of mealPlan)

Upward (child -> parent, via callback props):
  - RecipeCard calls `onToggleFavorite(recipeId)` on heart click
  - DayCard calls `onAddMeal(day, slot, recipe)` and
    `onRemoveMeal(day, slot)`
  - SearchBar and RecipeFilter call `onChange` handlers that update
    filter state in RecipesPage

Sibling communication (through shared parent state):
  - Favoriting a recipe on RecipesPage is reflected immediately on
    FavoritesPage, because both read the same `favorites` state
    from App
  - Adding a recipe to the meal plan from RecipeDetailPage updates
    what MealPlannerPage displays, via the shared `mealPlan` state

Local-only state (not lifted): search text, active filter
selections, modal open/closed, mobile nav menu open/closed — each
owned by the component that uses it.

4. PROPS FLOW (KEY EXAMPLES)

RecipeCard receives: recipe (object, required), isFavorite (bool,
default false), onToggleFavorite (func)

DayCard receives: day (string, required), meals (object, required),
onAddMeal (func), onRemoveMeal (func)

VideoPlayer receives: videoUrl (string, required), title (string,
default "Tutorial")

Card and Modal both accept a `children` prop for composition.

------------------------------------------------------------
5. STATE MANAGEMENT STRATEGY

- useState for all local and lifted state (search term, filters,
  favorites array, mealPlan object, isLoading/error booleans)
- useEffect (3 uses minimum):
  1. Load recipesData into state on App mount
  2. Read favorites/mealPlan from localStorage on mount
  3. Write favorites/mealPlan to localStorage whenever they change
- State is lifted to the lowest common ancestor that needs it (App
  for favorites/mealPlan/recipes; individual pages for their own
  filter/search state) to avoid unnecessary prop drilling.
